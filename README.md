# Algo Visualizer

An interactive web app for visualizing sorting, searching, data structure
and graph algorithms step by step. Built with React and Tailwind CSS.

## Progress

- [x] Sorting visualizers (Bubble, Selection, Insertion, Merge, Quick)
- [x] Searching visualizers (Linear Search, Binary Search)
- [x] Linear data structures (Stack, Queue)
- [x] Singly Linked List (Insert, Delete, Search, Traverse)
- [ ] Recursion & Call Stack
- [ ] Trees (BST & Traversals)
- [ ] Graphs (BFS & DFS)

## Tech Stack

React, JavaScript, Tailwind CSS, Vite

## Getting Started

```bash
git clone https://github.com/samarthlagad/algo-visualizer.git
cd algo-visualizer
npm install
npm run dev
```
